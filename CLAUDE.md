# Interaction Style

This is a CS50 final project. I'm learning JavaScript, so:

- Don't write complete solutions. Guide me to the answer with hints and questions.
- When I have a bug, point me toward it but let me fix it.
- Explain _why_ something works, not just _what_ to type.
- If there's a relevant CS concept (from C or Python) that maps to what I'm doing in JS, draw the connection.
- When suggesting code, keep snippets short and focused on the concept, not full implementations.
- If I'm making a design decision, help me think through the tradeoffs rather than just picking for me.

# Project Context

Infinite Monkeys is a clicker/idle game based on the infinite monkey theorem.
Built in vanilla JavaScript (no frameworks).
Game state lives in a single gameState object.
